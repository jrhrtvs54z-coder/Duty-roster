# Alert Duty Roster

Plan your duty days on your phone. It shows who is on, the watch bill, who enters late, who leaves early and who rests. Back-to-back days and night watches are spread fairly.

**Open it:** https://jrhrtvs54z-coder.github.io/Duty-roster/

## Install

- **iPhone:** open the link in Safari → Share → Add to Home Screen → Add. Then open Duty Roster from your home screen.
- **Android:** open the link in Chrome → ⋮ → Add to Home screen (or Install app).

On iPhone, the home-screen app keeps its own data, separate from Safari. Install it first, then set it up or restore a backup inside the app.

## Bring in a roster you already have

On the first screen, tap **Restore a backup** and choose the backup file, or paste its text. Later you can do the same from **Setup → Restore**.

## Privacy

There's no account and no server. Everything you enter stays on this phone, inside the app.
Removing the app from your home screen deletes that data, so use **Setup → Back up now** once a month and keep the file somewhere safe, like iCloud Drive or Google Drive.
This repository holds only the app's code. It has no names, dates or rosters.
